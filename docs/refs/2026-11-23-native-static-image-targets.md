# Native static image targets — 2026-11-23

These source observations inform the [native static profile](../architecture/adaptation-and-dialects.md#native-static-images). Model activation remains deployment configuration.

| Target | Official contract and observed boundary |
|---|---|
| `qwen-image-3.0-pro` | The [Aliyun native API](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference) supports synchronous `parameters.response_format=b64_json`. The [Token Plan example](https://help.aliyun.com/zh/model-studio/token-plan-image-generation) uses a URL, but the same inline option works on both configured origins. Native results carry PNG data URLs, a `stop` terminal and image-count/dimension metering, but no `created`. Aliyun documents a workspace-scoped OpenAI-compatible endpoint; the configured legacy DashScope origin does not serve that image path. Do not infer OpenAI compatibility from model availability or reuse a response-head date as a creation timestamp. |
| `gemini-nano-banana-2.1` | [Gemini image generation via generateContent](https://ai.google.dev/gemini-api/docs/generate-content/image-generation) specifies `TEXT` and `IMAGE` response modalities; the native result completed with inline JPEG, `STOP` and no creation report. [Released on October 6](https://ai.google.dev/gemini-api/docs/changelog), it supersedes `gemini-3.1-flash-image`. `gemini-3-pro-image` and `gemini-3.1-flash-lite-image` are distinct variants; the [migration table](https://ai.google.dev/gemini-api/docs/deprecations) directs Imagen 4 users to Nano Banana 2.1. |
| `grok-imagine-image-2.0` | [Released on August 7](https://x.ai/news/grok-imagine-image-2), the [standalone endpoint](https://docs.x.ai/developers/rest-api-reference/inference/images) supports `b64_json`, reports artifact MIME and uses exactly 10 billion ticks per USD. The configured OAuth binding returned an inline JPEG with MIME and cost reports but no `created`. The native format and money cannot be inferred from the model name or mapped onto the strict GPT Image defaults. |
