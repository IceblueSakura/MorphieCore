# 无状态隐式缓存亲和实现计划

**状态：下一候选小片，未实施。** 当前中性 header 与显式投影继续有效；本计划不启用历史存储，也不修改现行 HTTP/OpenAPI 准入。启动行为变更前将所选范围记入 [current-focus](current-focus.md)，遵循 TDD；完整主线及终期目标归 [next-goal](next-goal.md#api-context-goals)。

## 目标与范围

客户端每次提交完整历史、未提供会话 ID 时，Gateway 在兼容目标内尽力复用亲和分组。命中失败仅损失优化机会，原请求仍按相同验证和执行规则处理；显式中性会话 ID 保持稳定方案。

采用[隐式亲和合同](../architecture/protocol-and-lowering.md#implicit-cache-affinity)。先覆盖已有 Chat/Responses 路径的文本与普通 function 完整轮次；未声明前缀编码的组合直接未命中，不为提高命中率放宽 opaque、媒体或上下文投影。

非目标：跨 Provider 缓存、回答缓存、历史正文保存/恢复、相似搜索、自动摘要、凭据粘性/动态路由、额外 retry/fallback，以及 Anthropic 原生 cache breakpoint/TTL 的完整接入。F 的载荷交付和固定消费者不以本片通过替代验收。

## 实施顺序

以下三步构成一个最小纵向闭环，不只交付未接线的缓存容器。

### 1. 固定摘要与作用域

- 复用最终目标投影的内容权威，为所选路径定义有版本的前缀编码与有限完整 item 检查点；保留必要顺序、参数精度与 replay 值，不采用进程内 identity 或 Debug 作为跨请求摘要。
- 从已验证完整的请求/输出产生后继可匹配记录；无可证明前缀、失败、取消或未闭合输出不制造完整记录。不能为了登记索引恢复已删除正文或省略必需字段。
- Gateway/执行边界提供已选目标的兼容授权域；纯编码不访问 registry、凭据或存储。无法获得适用域时跳过推断，不补造跨账号兼容性。
- 先写独立摘要预期与编辑/作用域失败例，再实现所选算法；哈希值只用于亲和查询，不进入历史授权或 replay 证明。

### 2. 有界索引与候选局部接线

- 在 Gateway 内实现短 TTL、可禁用的内存索引，只保存合同限定的元数据。实现前固定 TTL、最大条目/累计 bytes、每请求检查点及并发访问界限；用可控时钟验证期限，不用 sleep 掩盖竞态。
- 在不改变固定候选/凭据选择的前提下查询适用域，为该候选确定亲和提示；显式来源优先，推断结果不回填为调用者 conversation identity。
- 将选择结果交给现有纯投影与 prepare，保持预检和实际发送一致；各候选仍从同一原请求开始，不把前一候选的提示带入不兼容域。
- 索引故障、过期、淘汰或预算不足按未命中处理。只记录闭合的命中来源/失败类别，不输出 hash、会话 ID、正文或高基数标签。

### 3. 验证与收口

- 最低 owner 验证摘要/TTL/容量和投影；只保留一个有独立价值的生产 Router→synthetic 上游接线检查，确认完整请求语义及非亲和字段不变。
- 按[开发指南](../development.md)执行受影响离线基线。真实收益采用[受控 probe](../probes.md)的有限代表性目标与请求矩阵，先固定预算、期限与清理；不扩大 Provider/model 库存或反复试到命中。
- 索引命中、实际出站提示、上游 cache-read/usage 分开报告。上游未报告或未命中不伪造成成功，也不成为放宽正确性边界的理由。

## 独立反例与验收

| 反例 | 必须保持的结果 |
|---|---|
| 完整首轮后追加消息或工具结果 | 所选精确前缀可复用分组，发送的完整历史不被删改 |
| 显式会话 ID；多个会话共用标准 cache key | 显式分组稳定且独立，隐式索引不覆盖显式意图 |
| 改 system/tools/参数顺序、编辑历史或压缩 | 不误认旧前缀；无法匹配时正常处理完整请求 |
| 同摘要、不同主体/Provider/Model/授权域或投影版本 | 不复用不兼容域的索引，不改变候选顺序 |
| TTL 到期、容量淘汰、禁用、并发分支或索引故障 | 可降为新分组；不加请求、不猜历史、不越过原验证 |
| JSON/SSE、取消、断流与未闭合工具参数 | 只发布合法的前缀记录，不把 partial 变成完整历史 |
| 无源正文的缓存索引命中或已失效 opaque | 命中不恢复内容，不解除必要 replay 检查 |

退出条件：上述所选闭环与离线基线成立，资源界限和不可覆盖的组合明确，当前 HTTP 行为与文档同步。移除已完成计划内容并停止；不自动进入终期历史服务或缓存稳定性专项。
